Politique de Confidentialité

ExcelCompiler v3.2

Dernière mise à jour : 4 juillet 2025

Résumé : ExcelCompiler respecte votre vie privée. Nous ne collectons, ne stockons ni ne partageons vos données personnelles ou fichiers Excel.

1. Informations que nous collectons

Nous NE collectons AUCUNE donnée personnelle :

  • ❌ Aucun fichier Excel/CSV traité
  • ❌ Aucune donnée contenue dans vos fichiers
  • ❌ Aucune information personnelle
  • ❌ Aucun historique de navigation
  • ❌ Aucune donnée biométrique

Données techniques locales uniquement :

  • ✅ Logs d'erreurs (stockés localement)
  • ✅ Préférences utilisateur (stockées localement)
  • ✅ Historique de session (stocké localement)

2. Utilisation des informations

Toutes les données restent sur votre ordinateur :

  • 📁 Traitement des fichiers Excel/CSV en local
  • 🔧 Amélioration de l'expérience utilisateur
  • 🐛 Diagnostic des erreurs (logs locaux)
  • 💾 Sauvegarde des préférences

3. Partage des informations

Nous ne partageons JAMAIS vos données :
  • ❌ Aucune transmission vers des serveurs externes
  • ❌ Aucun partage avec des tiers
  • ❌ Aucune vente de données
  • ❌ Aucune analyse comportementale

4. Sécurité des données

Mesures de sécurité intégrées :

  • 🔒 Chiffrement des fichiers temporaires
  • 🛡️ Validation d'intégrité des fichiers
  • 🚫 Blocage des fichiers suspects
  • 🗑️ Suppression automatique des fichiers temporaires
  • 📊 Limitation de la taille des fichiers

5. Stockage des données

Données stockées localement :

  • 📄 Fichiers de configuration : %APPDATA%/ExcelCompiler/
  • 📝 Logs d'erreurs : ./logs/
  • 💾 Sauvegardes de session : ./backups/
  • ⚙️ Préférences utilisateur : ./config/

6. Vos droits

Vous contrôlez entièrement vos données :

  • 🗑️ Suppression : Désinstallez l'application
  • 📂 Accès : Consultez les dossiers locaux
  • ✏️ Modification : Éditez les fichiers de configuration
  • 🚫 Blocage : Désactivez le logging dans les paramètres

7. Cookies et technologies similaires

ExcelCompiler n'utilise pas de cookies car il s'agit d'une application desktop, pas d'une application web.

8. Conformité réglementaire

ExcelCompiler respecte :

  • ✅ RGPD (Règlement Général sur la Protection des Données)
  • ✅ CCPA (California Consumer Privacy Act)
  • ✅ Microsoft Store Privacy Requirements
  • ✅ Standards de sécurité Windows

9. Applications tierces

ExcelCompiler utilise ces bibliothèques open source :

  • 🐍 Python 3.x (Licence PSF)
  • 📊 pandas (Licence BSD)
  • 🖥️ PyQt6 (Licence GPL/Commercial)
  • 📄 openpyxl (Licence MIT)

Aucune de ces bibliothèques ne collecte vos données.

10. Mises à jour de cette politique

Cette politique peut être mise à jour. Les changements seront :

  • 📢 Notifiés dans l'application
  • 📅 Datés dans le document
  • 📝 Documentés dans les notes de version
